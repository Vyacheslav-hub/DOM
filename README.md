# DOM

[![CI](https://github.com/Vyacheslav-hub/DOM/actions/workflows/ci.yml/badge.svg)](https://github.com/Vyacheslav-hub/DOM/actions/workflows/ci.yml)

**[Демо на GitHub Pages](https://vyacheslav-hub.github.io/DOM/)**

Игровое поле 4×4 — перемещение персонажа в DOM Tree (Webpack, Babel, ESLint, Jest, GitHub Actions).

## Скрипты

| Команда | Описание |
|---------|----------|
| `npm start` | Webpack Dev Server (разработка) |
| `npm run build` | Production-сборка в `dist/` |
| `npm run lint` | ESLint |
| `npm run test` | Jest (`--passWithNoTests`, если тестов нет) |
